# Яндекс Игры: действия после создания аккаунта

Актуально на 4 октября 2026 года. Это отдельная инструкция для этапа в консоли Яндекса. Локальная подготовка и материалы описаны в [publication/README.md](publication/README.md), результаты проверки — в [qa/yandex-publication.md](qa/yandex-publication.md). Аккаунт, черновик, товар и тестовые логины пока не созданы; настоящие платежи и реклама не проверены на площадке.

## 1. Аккаунт и монетизация

- [ ] Создать Яндекс ID и зарегистрировать аккаунт в [Консоли разработчика](https://games.yandex.ru/console/). Аккаунт должен принадлежать владельцу игры: перенос игры между аккаунтами требует обращения в поддержку.
- [ ] Изучить и оформить доступную для владельца схему договора и монетизации. Подготовить сведения и реквизиты, которые запросит консоль. Не публиковать реквизиты, токены и секретные ключи в Git.
- [ ] Подключить рекламную монетизацию и инап-покупки по доступной в аккаунте схеме. Для этой игры нужны полноэкранные межуровневые показы, добровольный rewarded и один постоянный товар. Стики-баннеры не используются.
- [ ] Указать рабочую почту поддержки владельца и проверить право на распространение исходников, текстов и материалов. Состав и происхождение ресурсов — в [publication/README.md](publication/README.md).

Точная форма подключения и доступность покупок зависят от аккаунта и условий сервиса. Следовать актуальным экранам консоли: [управление аккаунтом](https://yandex.ru/dev/games/doc/ru/console/manage-account), [монетизация](https://yandex.ru/dev/games/doc/ru/services/about-monetization), [загрузка игры](https://yandex.ru/dev/games/doc/ru/console/add-new-game).

## 2. Черновик и карточка

- [ ] Перед загрузкой выполнить `npm ci`, затем `npm run prepare:yandex`. Это создаст папку `artifacts/yandex-publication/` со сборкой, медиаматериалами, текстами и контрольными суммами.
- [ ] Добавить новую игру, записать её ID в этот документ. Не использовать черновик другой игры.
- [ ] Загрузить **только** `game.zip` из подготовленной папки в поле архива. Иконки, обложки, скриншоты и видео загружаются в свои поля отдельно; вся папка материалов не является игровым архивом.
- [ ] Указать версию `1.0.0`; платформы — десктоп, Android, iOS; ориентация — любая. ТВ не выбирать: игра не готовилась для пульта, а покупки на ТВ запрещены.
- [ ] Включить **«Игра использует облачные сохранения»**: игра вызывает `player.getData()` / `player.setData()`.
- [ ] Выбрать русский и английский. Заполнить обе вкладки текстами из [publication/store-listing.md](publication/store-listing.md). Удалить автоматически добавленные языки, которых нет в игре; проверить настройки AI-описаний, чтобы не обещать неподдерживаемые языки.
- [ ] Проверить уникальность названий в каталоге: **Разгадай и узнай** / **Solve & Discover**. Если название занято, согласовать новое и одновременно обновить игру, тексты и обложки.
- [ ] Категории: головоломки и, если доступна в консоли, обучающие игры. Теги выбрать по фактическому содержанию. Предварительный рейтинг — **6+**; владелец должен сверить его с действующими критериями консоли для всей библиотеки карточек.
- [ ] Для каждого языка загрузить `icon.png`, соответствующую `cover-ru.png` / `cover-en.png`, два десктопных и два мобильных скриншота, соответствующее горизонтальное видео. Maskable-иконка подготовлена дополнительно.
- [ ] Вставить комментарий для модератора из файла текстов. При желании включить **отсроченную публикацию** с причиной «Проверка настроек монетизации перед релизом», чтобы успешная модерация не открыла игру сразу.
- [ ] Проверить разрешённые хосты и страны распространения. Не включать дополнительные хосты без тестирования. Путь SDK `/sdk.js` уже настроен для хостинга Яндекса; ID игры и ключ в исходники вставлять не требуется.

Стандарты полей могут измениться. Сверить подготовленные файлы с подсказками в текущем черновике: [заполнение черновика](https://www.yandex.ru/dev/games/doc/ru/console/add-new-game/draft).

## 3. Товар отключения рекламы

- [ ] Подключить покупки и добавить **один** активный товар с ID **`disable_ads`**. Другие активные товары не создавать: их нет в интерфейсе игры.
- [ ] Заполнить название и описание на ru/en из файла текстов. Они прямо указывают: отключается реклама между уровнями, добровольные ролики за бонусы остаются доступны.
- [ ] Установить цену в консоли. Число, валюта и её изображение в игре берутся из `getCatalog()`; цена не задана в коде.
- [ ] Настроить постоянный товар согласно актуальной форме консоли. Игра подтверждает право через `getPurchases()` и **не вызывает `consumePurchase()` для disable_ads**. Это постоянная покупка, которую нужно восстанавливать при следующем запуске. Инструкции о консумировании расходуемых товаров к ней не применять.
- [ ] Добавить тестовый логин для покупок по инструкции Яндекса. Убедиться, что именно этот аккаунт используется для теста; не проводить проверку реальными списаниями по ошибке.
- [ ] Если покупки пока нельзя подключить, оставить каталог без активного товара: предложение покупки скроется. До публикации нужно отдельно подтвердить в консоли рекламную монетизацию и выбрать, будет ли товар доступен в первом релизе.

Основания: [SDK покупок](https://yandex.ru/dev/games/doc/ru/sdk/sdk-purchases), [требования к покупкам](https://yandex.ru/dev/games/doc/ru/requirements/1/13). Возвраты и отключение товара проверить доступными средствами тестового окружения; локальные моки этого не подтверждают.

## 4. Обязательная проверка в черновике

Открыть игру через кнопку консоли **«Открыть с debug-панелью»** или с `debug-mode=16`. Это панель платформы; собственная кнопка «Дебаг» из локальной разработки в релиз не входит. Проверять сохранения и покупки с **одной** открытой игровой сессией.

- [ ] **Старт:** нет ошибок DevTools; загружаются `/sdk.js`, модуль, CSS, SVG и Worker. Game Ready отправляется после открытия доступного интерфейса; нет пустого экрана и повторного лоадера после рекламы.
- [ ] **Язык:** с автоматической настройкой/новым профилем SDK mocks `ru` и `en` дают правильный интерфейс и индикатор `I18N is used`; `uk` → ru, `tr` → en. Проверить факт, чтение, коллекцию, ошибки, rewarded и покупку. Ручной язык переживает перезапуск.
- [ ] **Сохранения:** сделать ход, выиграть, выбрать тему, добавить факт в избранное, сменить настройки. Дождаться статуса «Прогресс сохранён в Яндексе» в настройках; закрыть игру и открыть её тем же аккаунтом на другом устройстве/браузере. Попытка, повороты, подсказки, карточки и настройки должны восстановиться. Проверить также гостевой запуск, недоступную сеть и очистку облака через панель Яндекса.
- [ ] **Смена аккаунта:** открыть штатный диалог выбора аккаунта Яндекса. Игра останавливает запись старому игроку и перезапускается после закрытия диалога. Проверить, что профиль и отключение рекламы не переносятся другому аккаунту.
- [ ] **Расхождение сохранений:** изменить профиль офлайн на одном устройстве, а затем онлайн на другом. При подключении первого устройства должен появиться выбор двух версий; проверить оба варианта на тестовом аккаунте. Автоматическое слияние ходов не предусмотрено.
- [ ] **Пауза:** кнопка меню, потеря фокуса, сворачивание, входящая платформа-пауза, реклама и оплата останавливают ввод и звук. Время попытки не растёт в паузе. Закрытие одного окна не снимает другую причину паузы.
- [ ] **Мобильный экран:** Android Chrome/Яндекс Браузер, iOS Safari и приложение Яндекс. Проверить переход в полноэкранный режим после «Играть», поворот, системные безопасные области, возврат из фона, долгий тап, отсутствие выделения/контекстного меню на поле и swipe-to-refresh. Проверить поиск в коллекции с открытой клавиатурой.
- [ ] **Десктоп:** Chrome, Яндекс Браузер, Firefox, Opera, Safari на доступных машинах. Проверить мышь, Tab, стрелки, Enter, пробел, Escape, размеры окна и отсутствие системного скроллбара. Заявлять платформы только после реальной проверки.
- [ ] **Rewarded:** при пустом запасе подсказок открыть явное предложение, отказаться и продолжить игру; посмотреть ролик и получить ровно +1 подсказку. На поражении получить одну дополнительную ошибку. Закрытие без `onRewarded` не даёт бонус. Повтор уровня доступен без рекламы.
- [ ] **Interstitial:** после минимум пяти новых побед и трёх минут активной игры перейти по «Следующий уровень». Проверить показ, отказ/нет заполнения, выход по рекламе и возврат. Затем частота — минимум три победы и три активные минуты; меню/чтение/фон не ускоряют показ.
- [ ] **Покупка:** проверить отмену и повтор; успешную покупку; обновление страницы до закрытия результата оплаты; перезапуск; восстановление тем же аккаунтом в другом браузере. После покупки interstitial отсутствует, добровольные бонусы работают. Через SDK mocks проверить валюту `TST` и смену иконки. При пустом каталоге покупка не предлагается.
- [ ] **Длительная игра:** проверить поля 4×4, 5×5, 6×6, несколько связей, отмену, тупик, потерю трёх ошибок, уровни после 100 и большую коллекцию. Изменение версии не должно терять старые карточки и профиль.

Записать устройства, браузеры, дату и результат в [qa/yandex-publication.md](qa/yandex-publication.md). Локальная эмуляция размера не заменяет физический телефон; локальные SDK mocks не заменяют интеграцию с платформой.

## 5. Отправка и выпуск

- [ ] Устранить замечания платформенного теста, собрать новый пакет и проверить его контрольные суммы. Обновить архив и материалы, если менялся интерфейс или название.
- [ ] Сверить карточку, языки, платформы, монетизацию, товар, договор, контакты и отсутствие секретов. Проверить, что загружена нужная версия и нет пометки о разработке внутри игры.
- [ ] Отправить черновик на модерацию. При замечании сохранить его текст, исправить причину и повторить соответствующую проверку.
- [ ] После одобрения при отсроченной публикации нажать «Опубликовать» в выбранный момент. Проверить публичную ссылку и оба языка с обычного аккаунта.
- [ ] Записать ID игры, публичную ссылку, дату, версию, тестовый протокол и цену товара ниже. Проверять отзывы, ошибки и доход в консоли; следующие версии загружать в эту же игру, сохраняя ID карточек и совместимость сохранения.

## Данные выпуска — заполнить в консоли

- Владелец аккаунта: **ещё не указан**.
- ID игры и ссылка на черновик: **ещё не созданы**.
- Публичная ссылка: **ещё нет**.
- Контакт поддержки: **ещё не указан**.
- Монетизация/договор: **ещё не подключены**.
- Тестовый логин: **ещё не добавлен** (секреты сюда не записывать).
- Товар: **disable_ads**, цена: **ещё не установлена**.
- Платформенный тест: **не проводился**.
- Модерация/дата выпуска: **не отправлено**.
