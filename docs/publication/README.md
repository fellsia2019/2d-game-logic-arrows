# Предварительный пакет для Яндекс Игр

Подготовка 4 октября 2026 года. Названия: **Разгадай и узнай** / **Solve & Discover**. Версия первого выпуска — `1.0.0`. Пакет предназначен для загрузки и проверки в черновике; аккаунта и результатов модерации пока нет.

Основной порядок действий после регистрации — **[../yandex-after-account.md](../yandex-after-account.md)**. Фактические результаты проверки — [../qa/yandex-publication.md](../qa/yandex-publication.md).

## Получить пакет

Для проверки MP4 нужен `ffprobe` из FFmpeg в PATH; PNG проверяются без дополнительных библиотек.

```sh
npm ci
npm run prepare:yandex
```

Результат — `artifacts/yandex-publication/`:

- `game.zip` — только выпускная игра для поля «Архив».
- `media/` — оригинальная иконка 512×512 PNG, maskable-иконка, обложки 800×470 PNG на двух языках, по два реальных скриншота для десктопа 1280×720 и мобильного экрана 720×1280 на каждом языке, горизонтальные MP4 ru/en.
- `store-listing.md` — готовые тексты полей и товара. Источник — `store-listing.json`; длины проверяются при подготовке пакета.
- `after-account.md` — инструкция для консоли, монетизации, платформенных тестов и модерации.
- `manifest.json` — размеры и SHA-256 всех передаваемых файлов, версия и состояние Git на момент сборки.

Медиаматериалы находятся в репозитории и не входят в игровую сборку. Перед отправкой на модерацию пакет пересобирается из проверенного состояния `main`. Изменение числа фактов или названия требует обновления текстов и обложек.

## Что подготовлено в коде

Выпускная сборка использует относительные пути к ассетам и платформенный `/sdk.js`. В корне ZIP лежит `index.html`, файлы имеют допустимые имена, размер до сжатия проверяется против 100 000 000 байт. Из релиза удалены инспектор, панель разработки, галерея и тестовые страницы SDK.

Есть гостевой запуск, автоматический язык SDK, Game Ready и разметка геймплея, независимые причины паузы, сохранение каждого действия, rewarded только по подтверждённому callback, редкий interstitial после победы и постоянная покупка `disable_ads`. Предложение покупки скрывается при отсутствии товара в каталоге. Полный экран запрашивается через SDK по действию игрока на mobile/tablet; отказ браузера не блокирует игру. На поле запрещено контекстное меню; системная прокрутка и overscroll отключены, собственная прокрутка длинных окон сохранена. Мобильная альбомная раскладка показывает поле и все действия рядом.

## Облачный профиль

`src/platform/cloud.ts` загружает данные через `getPlayer()` и `getData([arrowProfileV1])` **до** подготовки кампании и Game Ready. Авторизация не запрашивается автоматически. При первом подключении можно перенести существующий локальный профиль, если облако пустое. При смене владельца локальная копия предыдущего аккаунта не импортируется. Штатный диалог смены аккаунта прекращает синхронизацию и перезапускает игру.

Ходы немедленно пишутся в localStorage; облако получает последнюю целую копию профиля через `setData(data, true)`, не чаще одного запроса в четыре секунды и без параллельных записей. Статус «Прогресс сохранён в Яндексе» появляется только после подтверждения записи. Для перехода на другое устройство сначала дождаться этого статуса. Восстанавливаются seed и номер кампании, попытка и отмены, результаты, коллекция, избранное, темы, подсказки, настройки и язык. Право отключения рекламы восстанавливается отдельно через платежный SDK; токены покупки не копируются в профиль.

При неудачной загрузке облака игра продолжает локально и **не отправляет** неподтверждённый профиль поверх неизвестного серверного. При ошибке записи последняя копия остаётся на устройстве и повторяется через 15 секунд; отметка несинхронизированных изменений переживает перезапуск. Если локальная копия имеет несинхронизированные изменения, а сервер изменился после последнего подтверждённого снимка, игра предлагает выбрать одну версию перед стартом. Номер уровня и число карточек помогают выбрать; обе копии сохраняются в локальный резерв при доступном хранилище. По часам устройства победитель не определяется. При повреждённой или неизвестной версии облака перезапись запрещена. Одновременная игра на разных устройствах не поддерживает слияние ходов; платформенную приёмку проводить в одной сессии, как рекомендует Яндекс для покупок.

Лимит SDK — 200 КБ на игрока. Защитный порог отправки — 190 000 байт: большие профили не обрезаются и сохраняются локально с явным статусом. Это ограничение для очень длинной бесконечной кампании; перед значительным расширением истории нужна компактная схема облачного профиля. Локальные тесты проверяют эту защиту, но настоящий сервер Яндекса ещё не проверен.

Локальная проверка: `http://localhost:5174/tests/fixtures/yandex-payments.html?cloud&owner=qa`. Кнопка «Тест: загрузить из облака» удаляет только тестовую копию профиля на устройстве и перезапускает игру; сервер в этом тесте имитируется отдельным ключом localStorage. `&cloud-offline` имитирует ошибку загрузки. Это тест механизма восстановления, не доказательство работы с аккаунтом или другим устройством.

## Материалы и права

- Стрелки, иконки, интерфейс и промографика созданы в проекте. Иконка и обложки — отдельные композиции из формы стрелки и палитры игры, не скриншоты. Исходники — SVG в `media/` и `scripts/generate-publication-assets.py`. Для повторного экспорта нужны Python, Pillow, CairoSVG и системный Segoe UI в Windows; шрифт в пакет не включён.
- Скриншоты и видео сняты из `dist-yandex` при реальном прохождении через мышь/клавиатуру; в них нет debug-панели, тестовой оплаты, интерфейса браузера и чужого геймплея. Размеры и форматы проверяются при подготовке пакета. Источники записи и проверка кадров описаны в протоколе QA.
- Музыка и короткие звуки синтезируются кодом проекта; внешние аудиофайлы и системный медиаплеер не используются.
- 604 карточки ru/en используют собственные краткие формулировки с первоисточниками и датой проверки в `src/data/facts*`. Пользователь видит название источника без внешней ссылки. Редакционные правила — [../content-policy.md](../content-policy.md). Автоматический поиск запретных тем и проверки структуры не заменяют решение модератора по каждой карточке.
- В игре нет сторонних runtime-зависимостей из npm. TypeScript, Vite и Vitest служат инструментами разработки; они не распространяются как отдельные приложения в игровом ZIP. Владелец подтверждает права и принимает условия платформы при регистрации.
