# Разгадай и узнай

Рабочий вертикальный срез головоломки для Яндекс Игр. Полная проектная спецификация находится в `design-document.html`; текущая реализация — бесконечная персональная кампания с библиотекой из 160 фактов по восьми темам.

## Запуск

Нужен Node.js 22.12 или новее.

```sh
npm ci
npm run dev
```

Игра: http://127.0.0.1:5174/. Для проверки обычной production-сборки: `npm run build`, затем `npm run preview` (порт 4174). Порты закреплены для этой игры отдельно от «Арены наёмников»: Vite завершает запуск с ошибкой, если указанный порт занят, вместо перехода на случайный следующий. HTML игры нужно открывать через сервер, а не двойным щелчком по файлу.

## Что реализовано

- Первый вход: визуальная демонстрация на настоящем поле без текстовых объяснений — затемнение, зелёный путь, палец, нажатие и уход одной стрелки. Показ можно пропустить; он запоминается в профиле и останавливается при потере фокуса. Учебный ход не расходует подсказки и ошибки. Кнопка «Как играть» под полем первого уровня возвращает три исходные стрелки и повторяет показ, сохраняя коллекцию и результаты.
- Все новые уровни генерируются для игрока с первого поля. В профиль записывается персональный seed, ID поля содержит версию генератора, seed и номер. Первые 50 готовятся параллельно с SDK до открытия интерфейса; на уровне 40 добавляются следующие 50, далее на 90, 140 и т. д. Подготовка уступает управление между небольшими партиями, в памяти остаётся текущий блок и ближайший следующий. Каждый кандидат проверяется по полной последовательности решения, включая повороты. Обновление страницы и «Заново» восстанавливают то же поле.
- Сложность: 1–10 — 4×4, 3–12 стрелок без связей; 11–12 — 4×4, 6–7 стрелок, обучение одной связи; 13–20 — 5×5, 9–12 стрелок, иногда одна связь; 21–40 — 5×5, 12–16 стрелок, иногда 1–2 связи; 41–60 — 6×6, 16–20 стрелок, иногда 1–2 связи; 61–100 — 6×6, 20–23 стрелки, иногда 2–3 связи. После 100 чередуются 4×4, 5×5 и 6×6 с плотностью 43–61% и 0–3 связями; сложность перестаёт расти. Одна связь поворачивает одну цель на 90° по часовой стрелке. Цепочки связей возможны. Нет поля 7×7 или иных типов клеток.
- Старые 100 JSON-уровней (59 обычных, 41 связанных) оставлены для чтения прежних сохранений и регрессионных тестов. Незавершённое старое поле сохраняется, следующий номер уже генерируется. Исходный офлайн-скрипт `scripts/generate-levels.mjs` не управляет новой кампанией.
- Свободный луч до края, три ошибки, повтор без ожидания, бесплатная отмена успешных ходов с восстановлением направлений на уровнях со связями. На обычных уровнях кнопки отмены нет. Успешный ход применяется сразу: вылет стрелки не блокирует следующие клики, несколько стрелок могут вылетать одновременно.
- Поиск безопасного хода в Web Worker. Учебные подсказки бесплатны; обычные расходуют общий запас профиля только при найденном решении. Начальный запас — пять на всю игру; переход и повтор уровня его не пополняют. В тупике предлагается отмена.
- 160 фактов с первоисточниками: по 20 для космоса, природы, технологий, искусства, истории, географии, науки и человека. Каждая победа, включая повтор уровня, случайно открывает ещё не полученную карточку выбранных тем. Пока этот набор не исчерпан, повторов нет. Затем показывается знакомый факт с подписью «Вспомним факт», без повтора предыдущей карточки, если есть выбор. Коллекция, поиск, фильтр, избранное и выбор тем; недавно открытые карточки находятся первыми.
- Две яркие темы по настройке устройства, видимые клетки, переливающиеся цветные стрелки с непрерывной фазой при обновлении поля и их вылет за край. Один игровой экран без хедера, футера и боковых панелей. Линейное прохождение: после победы открывается следующий уровень. В главном меню находятся продолжение, коллекция, темы фактов и настройки. Статистика прохождения находится в коллекции. Отдельной карты уровней нет; после завершения серии её можно пройти снова, сохранив коллекцию. Мышь, касание и клавиатура, звуки, уменьшение анимации, пауза. Отмена хода бесплатная и появляется только на уровнях со связанными стрелками.
- Оригинальная фоновая музыкальная петля: мягкая инструментальная мелодия 78 BPM, отдельный сохраняемый переключатель от звуков ходов. Работает в меню и при чтении карточек, приостанавливается в фоне и во время рекламы; аудио запускается после действия игрока. Старые сохранения совместимы.
- Единая система оформления: зелёные основные действия, янтарные звёзды, нейтральные панели и собственная палитра каждой темы фактов: сиреневая для космоса, мятная для природы, голубая для технологий, коралловая для искусства, золотистая для истории, бирюзовая для географии, орхидейная для науки, персиковая для человека. Светлые и тёмные варианты хранятся по slug в `src/ui/topic-palettes.ts` и используются карточками, выбором тем и фильтрами галереи. В коллекции, темах и настройках есть закреплённая кнопка «Назад». Кнопки тем сохраняют высоту 56 px и постоянное место под галочку; выбор обновляется без перерисовки окна. Объяснения раскрываются JS-аккордеоном с CSS Grid `0fr → 1fr`, без измерения высоты. Работают Enter, Space и уменьшение движения; раскрытое состояние сохраняется при действиях в карточке. Hover-переходы для всех элементов — 0,3 s ease, при уменьшении движения они отключаются. Все иконки — SVG в единой системе; эмодзи и текстовые символы как значки не используются. Экран победы разделён на успех, карточку и переход дальше. Обоснование дизайна — раздел 13 геймдока.
- Локальное сохранение всей попытки и профиля; резервная копия, проверка схемы, защита от повторных наград и конфликтов вкладок.
- Адаптер Яндекс SDK: Game Ready, разметка геймплея, платформенная пауза, rewarded и interstitial. В локальном режиме реклама отсутствует. Награда выдаётся только по `onRewarded`.

## Проверки и архив

```sh
npm run check
npm run package:yandex
```

`check` запускает 161 тест, TypeScript и сборку Яндекса с проверкой состава файлов. `package:yandex` создаёт `artifacts/osvobodi-pole-slice-yandex.zip`: `index.html` лежит в корне, ассеты используют относительные пути. В режиме `yandex` SDK загружается с `/sdk.js`, предоставляемого площадкой. Архив предназначен для тестового размещения в консоли, не означает прохождение модерации.

Результаты браузерной проверки: `docs/qa/vertical-slice.md`. Источники фактов и дата проверки записаны в `src/data/facts.ts` и тематических файлах `src/data/facts/`.

## Инструменты проверки

В локальной разработке и обычном production-preview кнопка «Дебаг» находится внизу справа. Панель работает поверх главного меню и результатов: можно выбрать любой из уже подготовленных уровней персональной кампании, нажать «Победа», добавить одну глобальную подсказку и сменить светлую/тёмную тему. Победа и подсказки записываются в профиль текущего адреса; проверяй их на отдельном origin порта 4174, если нужно сохранить основной профиль порта 5174.

`http://127.0.0.1:5174/victory-gallery.html` показывает все 160 карточек победы, фильтрует темы, переключает палитру. Объяснения раскрываются, избранное работает внутри страницы; игровой прогресс не меняется. Галерея использует тот же компонент победы, что и игра. Дебаг-панель и галерея исключены из сборки и архива Яндекс Игр; проверка сборки запрещает их присутствие.

Загрузка начинается со стилизованного HTML-экрана до исполнения игрового модуля. Прогресс декоративный и не достигает 100% до готовности интерфейса и завершения инициализации SDK. После открытия игры отправляется Game Ready. Ожидание SDK ограничено 10 секундами; при сбое доступен локальный режим. Эмблема и все значки лоадера — SVG. При отсутствии или удалении разметки загрузчика запуск продолжается без ошибки. Игра и галерея используют общую SVG-фавиконку.

## Реклама

Межстраничная реклама вызывается только после победы, по нажатию «Следующий уровень». Первый вызов требует минимум пяти новых побед и трёх минут активной игры. Следующие — минимум трёх побед и трёх активных минут после предыдущего показа. Меню, чтение фактов, учебная демонстрация и фон не считаются активным временем. Перед учебным уровнем вызова нет; после неудачной попытки выдерживается минута. Просмотр rewarded также отодвигает следующий межстраничный показ на три активные минуты.

Добровольная реклама: при нажатии «Подсказка» с пустым общим запасом на обычном уровне открывается окно «Подсказки закончились» с предложением посмотреть рекламу за одну подсказку и кнопкой «Не сейчас». Просмотр пополняет запас; игрок затем сам нажимает «Подсказка». Если SDK недоступен, окно сообщает об этом без кнопки просмотра; на экране поражения доступна одна дополнительная ошибка за просмотр. Повтор уровня, отмена, темы, коллекция и факты рекламу не вызывают. В локальном режиме настоящей рекламы нет; её callbacks проверены моками, проверка живой сети остаётся для размещения в консоли Яндекса.

## Как сохраняется прогресс

Сейчас используется только `localStorage` текущего адреса игры. Ключ `osvobodi-pole-profile-v1` содержит весь профиль: попытку, пройденные уровни, факты, общий запас подсказок и настройки. `osvobodi-pole-profile-v1-backup` хранит предыдущую валидную запись. Облачное сохранение Яндекса ещё не подключено. Награда хранится вместе с ID победившей попытки (`lastFactReward`): перезагрузка результата не выбирает другой факт и не пополняет коллекцию повторно. Новый ID попытки после повтора позволяет получить следующую карточку. Старые ID карточек, избранное и выбранные темы сохраняются; четыре новые темы можно включить в меню. Новый профиль начинает со всеми восемью темами.

Профиль записывается после действий и перед уходом со страницы. Резервная копия используется только при повреждённой основной записи. Отсутствие основного ключа означает начало с чистого профиля; старая копия удаляется при первой записи нового профиля.

Очистка хранилища при открытой игре не позволяет вкладке записать старый профиль обратно: игра обнаруживает удаление и предлагает обновить страницу. То же правило защищает изменения в другой вкладке, в том числе новый профиль с меньшей ревизией. Для сброса удаляй основной ключ или всё хранилище именно того адреса, где открыта игра, затем обновляй страницу. `localhost` и `127.0.0.1`, а также порты 5174 и 4174 имеют отдельные сохранения. При переходе с прежнего порта 5173 на 5174 создаётся отдельный локальный профиль; прежняя запись остаётся доступной по старому адресу. После любой победы доступен следующий уровень; конечного экрана кампании нет.

## Структура

`src/core` — чистые правила и транзакции профиля; `src/data` — уровни и факты; `src/solver` — поиск решения; `src/platform` — сохранение и SDK; `src/ui` — экраны; `src/main.ts` — контроллер. `src/data/generated-levels.ts` содержит версионированный генератор, `campaign.ts` — подготовку партий. Каждый уровень содержит проверяемую последовательность решения. Алгоритм уже выпущенной версии нельзя менять: новый алгоритм требует нового префикса ID с сохранением прежнего декодера.

## Работа с Git

В проекте используется одна ветка — `main`. Изменения фиксируются и отправляются из неё; дополнительные ветки создаются только по прямому запросу владельца проекта. Правило для агентов сохранено в `AGENTS.md`.

Удалённый репозиторий: [fellsia2019/2d-game-logic-arrows](https://github.com/fellsia2019/2d-game-logic-arrows), remote — `origin`.

В репозитории хранятся исходники, генератор и прежний каталог для совместимости, тесты, геймдок и материалы проверки. `node_modules`, каталоги сборок, ZIP-архивы и логи исключены через `.gitignore`; релизный архив воспроизводится командой `npm run package:yandex`.

## До полного релиза

Предстоят дальнейшее пополнение библиотеки фактов, балансировка генератора по игровым сессиям, облачный профиль и разрешение конфликтов, локализация, метрики, проверка реального SDK и рекламы в консоли Яндекса, тесты физических устройств, обложки и материалы публикации. Текущий локальный профиль не синхронизируется между устройствами. Соседняя игра использована как архитектурный ориентир и не изменялась.
